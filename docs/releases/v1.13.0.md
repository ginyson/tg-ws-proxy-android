# TgWsProxy SNI v1.13.0

- Добавлен режим **Cloudflare Proxy без TLS (порт 80)** для сетей, где TLS к CF proxy-доменам зависает даже с базовым SNI.
- Включение: остановить прокси → **Настройки → Cloudflare → Cloudflare Proxy без TLS (порт 80)** → снова запустить.
- Локальный адрес по-прежнему **127.0.0.1:1444**. Порт 80 относится к внешнему CF-соединению.
- Шифрование MTProto сохраняется, но дополнительной TLS-оболочки до Cloudflare в этом режиме нет. TLS включён по умолчанию, переключение только явное.
- Оба frontend (MTProto и SOCKS5) и диагностика используют выбранный транспорт. Переключение транспорта сбрасывает старые cooldown доменов.
- Direct и Worker не изменены. Выбор Telegram-клиента и прежний ключ подписи сохранены.

Проверки 19 ноября: независимый клиент на Pixel подтвердил настоящие ответы Telegram res_pq с проверенным nonce через порт 80 на нескольких доменах и DC2/DC4. Те же проверки прошли через установленный frontend 127.0.0.1:1444 на мобильной сети в intermediate и padded intermediate; пользователь подтвердил работу Plus. TLS на той же мобильной сети истекал по таймауту.

Нативные Go-тесты и 424 JVM-теста прошли.

Android 8.0+ / ARM64. Обновление устанавливается поверх версии 1.12.2 без удаления данных.
