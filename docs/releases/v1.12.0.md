# TgWsProxy SNI v1.12.0

- Исправлен Cloudflare Proxy: TLS SNI использует базовый домен, HTTP Host сохраняет `kwsN.<домен>`. Изменение работает для MTProto, SOCKS5 и самопроверки.
- Порт по умолчанию — **127.0.0.1:1444**. При первом открытии версии прежний порт по умолчанию 1443 переносится на 1444; другие порты сохраняются.
- «Применить в Telegram» открывает системный выбор установленного клиента, включая Plus и Beta.
- Отдельное приложение **TgWsProxy SNI**, пакет `io.github.malordin.tgwsproxy`.
- Добавлены сборки и подписанные релизы на GitHub-hosted Ubuntu.

После обновления нажмите «Применить в Telegram» заново, чтобы передать клиенту актуальный порт и секрет. Используется прежний ключ подписи форка; удалять первую сборку не требуется.

APK предназначен для Android 8.0+ / ARM64. Файл `.sha256` содержит контрольную сумму APK.
