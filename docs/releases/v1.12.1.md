# TgWsProxy SNI v1.12.1

- Порт по умолчанию **127.0.0.1:1444** — в настройках, ссылках Telegram, справке и подсказках. Прежний порт по умолчанию 1443 мигрирует при открытии приложения; другие порты сохраняются.
- «Применить в Telegram» открывает системный выбор установленного клиента, включая Plus и Beta.
- Сохранено исправление Cloudflare Proxy: базовый домен в TLS SNI, `kwsN.<домен>` в HTTP Host; работает в MTProto, SOCKS5 и диагностике.
- Подписанная сборка опубликована GitHub Actions. Пакет `io.github.malordin.tgwsproxy` и ключ подписи прежние: обновление устанавливается поверх первой сборки форка.

После обновления примените прокси в выбранном Telegram-клиенте заново, чтобы передать порт 1444 и актуальный секрет.

Android 8.0+ / ARM64. SHA-256 APK приложен отдельным файлом.
