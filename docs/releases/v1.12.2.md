# TgWsProxy SNI v1.12.2

- По умолчанию **127.0.0.1:1444**, включая ссылки Telegram, справку и подсказки. Прежний порт по умолчанию 1443 переносится при открытии приложения; другие порты сохраняются.
- «Применить в Telegram» каждый раз открывает системный выбор клиента. Android показывает все приложения для `tg://`, включая Plus и Beta; ограничение EXTRA_INITIAL_INTENTS на два дополнительных клиента не используется.
- Исправление Cloudflare Proxy: базовый домен в TLS SNI, `kwsN.<домен>` в HTTP Host. Применяется автоматически к MTProto, SOCKS5 и диагностике.
- Автосборка и публикация подписанного APK + SHA-256 через GitHub Actions на Ubuntu.

Пакет `io.github.malordin.tgwsproxy` и ключ подписи прежние: удалять первую сборку форка не требуется. После обновления примените прокси в выбранном клиенте заново для передачи порта 1444 и актуального секрета.

Android 8.0+ / ARM64.
