# TgWsProxy SNI v1.13.1

Исправлен дефолт: **Cloudflare Proxy без TLS (внешний порт 80) теперь включён по умолчанию** — в интерфейсе, настройках запуска, нативном runtime и диагностике.

На новых установках и при обновлении без сохранённого выбора рабочий режим включается автоматически. Ранее явно сохранённый выбор не перезаписывается. На Pixel, где режим уже был включён, ничего менять не нужно.

TLS остаётся доступен: остановить прокси → Настройки → Cloudflare → выключить «Cloudflare Proxy без TLS (порт 80)» → запустить снова.

Локальный адрес прежний: **127.0.0.1:1444**. Шифрование MTProto сохраняется; дополнительной TLS-оболочки до Cloudflare в режиме порта 80 нет. Ключ подписи прежний, удалять приложение не нужно.
